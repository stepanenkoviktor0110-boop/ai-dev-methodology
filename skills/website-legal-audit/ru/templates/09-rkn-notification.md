# Уведомление об обработке персональных данных

Подать на портале: **pd.rkn.gov.ru/operators-registry/notification**
(электронная форма заявления). Срок рассмотрения — около 10 рабочих дней.

## Поля для заполнения

| Поле формы РКН | Значение |
|----------------|----------|
| Наименование оператора | {{ORG_NAME}} |
| ОГРН/ОГРНИП | {{OGRN}} |
| ИНН | {{INN}} |
| Адрес | {{ADDRESS}} |
| Контактный email | {{EMAIL}} |
| Цель обработки | {{PROCESSING_PURPOSES}} |
| Категории субъектов | посетители сайта, клиенты, контрагенты (уточнить) |
| Категории ПДн | {{PDN_LIST}} |
| Перечень действий | сбор, запись, систематизация, накопление, хранение, уточнение, использование, передача, удаление, уничтожение |
| Способ обработки | смешанный |
| Правовое основание | ФЗ-152, согласие субъекта, договоры |
| Меры по обеспечению безопасности | организационные и технические (ст. 18.1, 19) |
| Место хранения / нахождение БД | территория Российской Федерации |
| Передача третьим лицам | {{THIRD_PARTIES}} |
| Трансграничная передача | [если HAS_CROSS_BORDER] да, страны: {{RECIPIENT_COUNTRIES}} [иначе] нет [/если] |
| Дата начала обработки | {{DATE}} |
| Срок/условие прекращения обработки | достижение целей либо отзыв согласия |

## Важно

- При трансграничной передаче — подаётся ОТДЕЛЬНОЕ уведомление до начала
  передачи (ст. 12 ФЗ-152), не путать с уведомлением об обработке.
- Для подачи электронно нужна усиленная квалифицированная электронная подпись.
- После подачи оператор попадает в реестр на `pd.rkn.gov.ru/operators-registry`.
