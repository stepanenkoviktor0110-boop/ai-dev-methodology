# РФ-ветка — аудит по российскому законодательству

Грузится при флаге `ru` (или как часть `both`). Аудитория и обработка ПДн в РФ.

> ⚠️ Не юрист. Черновик под проверку. Нормы сверяй по датам — менялись в
> 2024–2025 активно.

## Чеклисты (грузить по релевантности типа сайта)

- `references/01-personal-data.md` — ПДн (ФЗ-152). **Касается почти любого сайта**
  с формой, метрикой или cookie. Грузить всегда.
- `references/02-ecommerce.md` — реквизиты продавца, оферта, ЗоЗПП. Только если
  сайт что-то продаёт (интернет-магазин, приём оплат, заказы).
- `references/03-advertising.md` — маркировка интернет-рекламы (erid/ОРД/ЕРИР),
  запрет рекламы на запрещённых ресурсах. Только если есть платные размещения
  или реклама ведёт на этот сайт.

## Процесс РФ-ветки

1. Детектор (`common/detector.md`) → сводка.
2. Всегда прогнать `01-personal-data.md`.
3. Если продажи → `02-ecommerce.md`. Если реклама → `03-advertising.md`.
4. Отчёт по `common/report-template.md`.
5. Недостающие документы → собрать из `templates/` (см. ниже).

## Сборка документов из шаблонов

В `templates/` лежат болванки с переменными `{{...}}`. Алгоритм:

1. **Опросник переменных** — спроси разом всё, чего нет на сайте/в детекторе:
   - `{{ORG_NAME}}`, `{{OGRN}}` / `{{OGRNIP}}`, `{{INN}}`, `{{ADDRESS}}`
   - `{{EMAIL}}`, `{{SITE_URL}}`
   - `{{PROCESSING_PURPOSES}}` — цели обработки ПДн (под формы сайта)
   - `{{PDN_LIST}}` — какие поля собираются
   - `{{THIRD_PARTIES}}` — кому передаются данные (хостер, CRM, метрика, доставка)
   - `{{COOKIE_LIST}}` — какие cookie используются
   - для магазина: условия оплаты/доставки/возврата
2. Заполни все нужные шаблоны разом, подставив переменные.
3. Каждый документ помечен `draft: true` + дисклеймер про юриста — не снимай.

## Ключевые нормы РФ (актуально на 2026, сверяй даты)

- **Уведомление РКН** об обработке ПДн — обязательно почти всем с 30.05.2025.
- **Отдельное согласие** на ПДн (не в составе оферты, отдельные галочки на цель)
  — с 01.09.2025.
- **Локализация БД в РФ** (ч.5 ст.18 ФЗ-152) — первичный сбор только на серверах
  РФ, с 01.07.2025 нельзя собирать сразу в зарубежную базу.
- **Трансграничная передача** — отдельное уведомление РКН до начала передачи
  (Google Analytics, Google Fonts, Meta Pixel = трансграничная передача).
- **Оборотные штрафы** 1–3% выручки за повторную утечку ПДн.
- **Маркировка рекламы** (erid/ОРД/ЕРИР) + запрет рекламы на запрещённых
  ресурсах с 01.09.2025.

Точные суммы штрафов и реквизиты норм — в reference-файлах, не дублируй здесь.
