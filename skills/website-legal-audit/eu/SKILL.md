# ЕС-ветка — аудит по GDPR / ePrivacy

Грузится при флаге `eu` (или как часть `both`). Применяется, когда сайт
обрабатывает данные субъектов из ЕС/ЕЭЗ (независимо от того, где сам бизнес —
GDPR экстерриториален, ст. 3).

> ⚠️ Не юрист. Черновик под проверку. UK после Brexit — отдельный UK GDPR (близок,
> но не идентичен); если есть британская аудитория — отметь это, нормы сверяй
> отдельно.

## Чеклисты

- `references/01-gdpr.md` — Privacy Policy (Art. 13/14), правовые основания,
  права субъекта, DSAR, передача за пределы ЕС. **Грузить всегда.**
- `references/02-eprivacy-cookies.md` — cookie-баннер, prior consent, reject-all.
  Грузить, если есть cookie/трекеры (почти всегда).
- `references/03-consumer-rights.md` — права потребителя при онлайн-продажах
  (Consumer Rights Directive). Только если сайт продаёт.

## Процесс ЕС-ветки

1. Детектор (`common/detector.md`) → сводка.
2. Всегда прогнать `01-gdpr.md`.
3. Если cookie/трекеры → `02-eprivacy-cookies.md`. Если продажи →
   `03-consumer-rights.md`.
4. Технический отчёт по `common/report-template.md`.
5. Недостающие документы → собрать из `templates/`.
6. Отчёт для заказчика по `common/client-report.md`.

## Сборка документов

В `templates/` — болванки с переменными `{{...}}` и условными блоками
`[если VAR]...[/если]`. Опросник переменных:

- `{{CONTROLLER_NAME}}`, `{{CONTROLLER_ADDRESS}}`, `{{CONTROLLER_EMAIL}}`
- `{{DPO_CONTACT}}` — контакт DPO, если назначен
- `{{EU_REP}}` — представитель в ЕС (ст. 27), если контроллер вне ЕС
- `{{SITE_URL}}`, `{{DATA_CATEGORIES}}`, `{{PROCESSING_PURPOSES}}`
- `{{LEGAL_BASIS}}` — основание по каждой цели (consent / contract / legitimate
  interest — конкретно, «business purposes» недостаточно)
- `{{RECIPIENTS}}`, `{{RETENTION}}`, `{{COOKIE_LIST}}`
- `{{INTL_TRANSFER}}` — передача за пределы ЕС + механизм (SCC / adequacy)
- `{{SUPERVISORY_AUTHORITY}}` — надзорный орган для жалоб

## Ключевые нормы (актуально на 2026, сверяй)

- **Privacy Policy по Art. 13** — обязательный набор сведений, ссылка под каждой
  формой и в баннере; ясный язык.
- **Prior consent** — некритичные cookie/трекеры НЕ грузятся до согласия;
  баннер при одновременной установке cookie = нарушение.
- **Reject-all** — кнопка «Отклонить всё» равной заметности с «Принять всё»;
  без pre-ticked; гранулярно по категориям; без dark patterns.
- **Права субъекта + DSAR** — ответ обычно в течение 1 месяца.
- **Передача за пределы ЕС** — только с механизмом (adequacy decision / SCC).
- **Штрафы** — до €20 млн или 4% мирового оборота; регуляторы проверяют
  техническую сторону (загрузку скриптов), не только вид баннера.
