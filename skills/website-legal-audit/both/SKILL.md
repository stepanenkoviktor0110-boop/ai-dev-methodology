# Комбинированный режим — РФ + ЕС

Грузится при флаге `both`: у сайта есть и российская, и ЕС-аудитория. Прогоняются
обе ветки, отчёт сводится без дублей.

> ⚠️ Не юрист. Черновик под проверку. Требования РФ и ЕС независимы и
> применяются параллельно — соответствие одной юрисдикции не отменяет другую.

## Порядок

1. **Детектор один раз** (`common/detector.md`) — сводка общая для обеих веток.
2. **РФ-ветка**: прогнать чеклисты `ru/references/` по применимости.
3. **ЕС-ветка**: прогнать чеклисты `eu/references/` по применимости.
4. **Свести отчёт** по `common/report-template.md`: одна таблица, в колонке
   «Норма» — и РФ-, и ЕС-нормы; повторяющиеся по смыслу требования объединить в
   одну строку с двумя нормами (см. ниже).
5. Технический отчёт → план работ → отчёт для заказчика (`common/client-report.md`).

## Что объединять, что держать раздельно

Объединяй в одну строку (требование совпадает по сути, нормы разные):

| Требование | РФ | ЕС |
|------------|----|----|
| Политика/Privacy Policy опубликована | ч.2 ст.18.1 ФЗ-152 | Art. 13 GDPR |
| Согласие — свободное, отдельное | ч.4 ст.9 ФЗ-152 | Art. 4(11), 7 GDPR |
| Cookie до согласия не грузятся / баннер | ст.9 ФЗ-152 | ePrivacy Art. 5(3) |
| Права субъекта + отзыв согласия | ст.9, 21 ФЗ-152 | Art. 15–22 GDPR |
| Реагирование на утечку | 24 ч, ст.21 ФЗ-152 | 72 ч, Art. 33 GDPR |

Держи РАЗДЕЛЬНО (специфично для одной юрисдикции):

- **РФ**: уведомление РКН (ст.22), локализация БД в РФ (ч.5 ст.18), маркировка
  рекламы (erid/ОРД/ЕРИР), запрет рекламы на запрещённых ресурсах.
- **ЕС**: reject-all равной заметности, legitimate interest как основание,
  представитель в ЕС (Art. 27), SCC для передачи, право на отказ 14 дней (CRD).

## Конфликты требований

Прямых конфликтов обычно нет — нормы складываются (берётся более строгая планка).
Реальное напряжение: **локализация РФ (данные россиян — в РФ)** vs **передача
данных ЕС-субъектов**. Решение — раздельные потоки данных по аудитории, не общая
БД. При обнаружении — эскалировать как архитектурный вопрос, не решать шаблоном.

## Документы

Собирай из обеих папок `templates/` по применимости:
- для РФ-аудитории → `ru/templates/`,
- для ЕС-аудитории → `eu/templates/`.
Не смешивай в один документ — это разные правовые режимы. На сайте, как правило,
два комплекта (RU/EN) либо геозависимая выдача.
