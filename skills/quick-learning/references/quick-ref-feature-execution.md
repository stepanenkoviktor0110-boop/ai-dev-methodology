# Quick Reference — Feature Execution

1. Верифицируй результат в реальной среде после деплоя (curl/лог/grep уникального маркера из нового коммита) — не объявлять "готово" без подтверждения (Seen: 4)
2. Спорные решения ДО генерации: артефакт > 200 строк → список решений с вариантами → утверждение → генерация (Seen: 1)
3. Субагент не завершил из-за внешней блокировки (права, permission) — lead делает сам через Write/Edit, не ретраить (Seen: 1)
4. Codex: один файл за раз — промт должен содержать `<completeness_contract>` с инструкцией писать файлы по одному (Seen: 1)
5. Codex: тесты прогоняет Claude — Codex sandbox не запускает vitest/vite (spawn EPERM на Windows) (Seen: 1)
6. Любое изменение — проверяй радиус поражения: sibling-группы, CORS/CSRF при смене домена, hotfix → audit wave, grep structurally-similar endpoints (Seen: 1)
7. Не подтверждай без проверки реальности: grep в коде до ответа, задача done только после реального эффекта в системе — файл создан ≠ фича работает (Seen: 1)
8. Серверные операции — проверяй preconditions (порт, push state, hung process) до дебага логики (Seen: 1)
9. Баг после деплоя — сначала upstream-инфраструктуру (платформа, маппинг веток), потом код (Seen: 1)
10. Несколько гипотез → evidence first: прочитать observable evidence ДО объявления диагноза, не hypothesis anchoring bias (Seen: 1)
