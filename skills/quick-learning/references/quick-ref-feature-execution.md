# Quick Reference — Feature Execution

1. Верифицируй результат в реальной среде перед объявлением "готово" — для cron: проверь лог через 5 мин после первого срабатывания (Seen: 3)
2. Субагент не завершает задачу → lead выполняет напрямую через Write/Edit, не ретраит субагент (Seen: 2)
3. Спорные решения ДО генерации: перед артефактом >200 строк — выписать решения с неоднозначностью, утвердить, только потом генерировать (Seen: 2)
4. Серверные операции — проверяй preconditions: порты, push state, SSH доступ, процессы (Seen: 2)
5. Изменение одного элемента из sibling-группы → проверить и применить к каждому «брату» + grep validation в structurally-similar routes (Seen: 2)
6. Пользовательские инструкции — уточняй scope: "не нужен" → UI или вся функциональность? (Seen: 2)
7. Не подтверждай без проверки реальности: "это работает?" → grep в коде до ответа (Seen: 2)
8. Async агент без прогресса 5 мин → kill и перезапуск, не "может ещё думает" (Seen: 1)
9. Task-файл содержит запрет ("NEVER X") → grep по запрещённому паттерну ДО коммита (Seen: 1)
10. Free tunnel перезапустился → считать новый URL и передать клиенту немедленно (Seen: 1)
