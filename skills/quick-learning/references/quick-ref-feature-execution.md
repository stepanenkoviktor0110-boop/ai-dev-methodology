# Quick Reference — Feature Execution

1. Верифицируй результат в реальной среде: после деплоя curl/лог/grep уникального маркера из нового коммита — «готово» только по факту (Seen: 4)
2. Спорные решения ДО генерации: артефакт >200 строк → список решений с вариантами → утверждение → генерация (Seen: 1)
3. Субагент заблокирован извне (права/permission) → lead выполняет напрямую через Write/Edit, не ретраить субагент (Seen: 1)
4. Серверные операции: проверяй preconditions (порт, push state, число процессов, подключение) до дебага логики (Seen: 1)
5. Пользовательские инструкции: уточняй scope — UI или вся функциональность; task-файл > prompt для значений (Seen: 1)
6. Любое изменение: проверяй радиус поражения — примени к каждому sibling, grep по всем structurally-similar местам (Seen: 1)
7. Не подтверждай без проверки реальности: grep/чтение источника до ответа; файл создан ≠ фича работает (Seen: 1)
8. Планирование задач: валидируй зависимости — wave(dep) < wave(task), state-файл от якоря, не от CWD (Seen: 1)
9. Делегировал работу, обязанную ПРОИЗВЕСТИ артефакт → проверь что артефакт реально существует (ls/grep/read); completion-сигнал ≠ deliverable (Seen: 1)
10. Мерж/деплой в mainline → читай живой HEAD/реальный symlink, гейти по descent от истинного состояния, не по nominal ref (Seen: 1)
