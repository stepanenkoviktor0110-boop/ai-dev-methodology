# Quick Reference — Design Critique

1. Choosing one representative detail per item across near-identical items — optimise the choice for difference across the set, not for quality within each item; extract every chosen detail and check for repeats (Seen: 1)
2. Mocking a screen that shows computed values or catalogue data an existing system owns — look up each value's producer first, copy its name, contract and wording verbatim, and mark only what is genuinely faked (Seen: 1)
