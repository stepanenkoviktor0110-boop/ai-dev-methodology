# Personal Brand — Форматы и приёмы

## Выбор формата

| Ситуация | Формат |
|---|---|
| Есть скрины UI/продукта, нужно показать кейс | A |
| Есть фото + список буллетов | B1 |
| Есть портретное фото + короткий заголовок | B2 |
| Есть фото + длинная цитата или нарратив | B3 |
| Серия карточек, интервью, карусель | B4 |
| Есть фирменные цвета бренда | C |

---

## Формат A — Кейс с устройством

Нейтральный светлый фон — воздух вокруг мокапов. Фото не используется.

**Зоны сверху вниз:**
1. Заголовок — крупный, uppercase, лёгкий вес, тёмный на светлом
2. Мокап(ы) планшета — 1 или 2. Два мокапа — оверлап, передний крупнее
3. Описание — буллеты, обычный регистр

**Декор:** изогнутая стрелка (SVG) соединяет описание с мокапом. Указывает на то, о чём идёт речь.

---

## Формат B1 — Фото + заголовок + список

Фото занимает нижнюю часть карточки. Текстовая зона — сверху, где фото светлее или нейтральнее.

**Структура:** ЗАГОЛОВОК → список буллетов → фото снизу

**Брендинг:** мелкая подпись канала — левый нижний угол.

---

## Формат B2 — Фото + центральный заголовок

Полноэкранное фото. Заголовок в нижней трети — там, где фото даёт однородную зону.

Подзаголовок меньшего размера под заголовком уточняет смысл.

---

## Формат B3 — Фото + плавающие цитаты

Фото на весь холст. Несколько текстовых блоков рассыпаны по карточке — каждый чуть сдвинут относительно предыдущего. Создаёт ритм разговора, не колонку.

Акцентная фраза внизу: bold italic, ложится на однородную зону фото.

---

## Формат B4 — Интервью / Диалог (карусель)

Серия карточек с единым цветовым тоном. Стрелка `→` внизу справа — сигнал "листай дальше".

**Структура:**
- Вопрос: тире + UPPERCASE BOLD (верхняя часть)
- Ответ: тире + обычный регистр (нижняя часть, на зоне свечения)

**Брендинг-бейдж:** таблетка с названием канала — левый нижний угол рядом со стрелкой.

**Свечение:** цветной световой ореол фирменного цвета под текстовой зоной. Не затемнение — именно свечение. Решает две задачи одновременно: читаемость текста + брендирование фона. Реализуется через `radial-gradient` с прозрачностью.

---

## Формат C — Фирменный стиль

Используется когда у автора/бренда есть свои цвета.

**Цветовая система:** один цвет — заголовки и акценты, второй — тело текста. Цвета не придумываются — берутся готовые от бренда.

**Два шрифта:** serif display для заголовков + sans-serif для тела. Намеренный контраст — не ошибка, а приём.

**Фон:** органическая текстура (бумага, дерево, ткань, бетон) вместо однородного цвета. Добавляет живость без визуального шума.

---

## Универсальные приёмы

**Однородная зона объекта как подложка текста**
Когда на фото есть большой объект с однородной поверхностью (небо, поверхность кофе, стена, вода) — текст ложится туда без overlay. Нет деталей, конкурирующих с текстом. При кадрировании направлять однородную зону под текстовый блок.

**Обесцвечивание фото**
`filter: grayscale(100%)` убирает конкуренцию цветов фото и текста. Цветной текст поверх ЧБ фото читается всегда. Используется когда фото цветное, но цвета мешают тексту.

**Цветовое тонирование**
Полупрозрачный overlay фирменного цвета поверх фото приводит серию карточек к единой цветовой температуре. Фото остаётся узнаваемым, но "окрашено" в цвет бренда.

**Список через символы**
`—` или `•` выровненные вертикально создают визуальный "трек" слева. Типографический приём, не HTML-список. Читается как список, ощущается как авторское оформление.

**Список внутри абзаца через слэш**
`опыта / знаний / ресурсов / денег` — перечисление однородных объектов в строке. Легче визуально чем буллеты, подходит когда объектов много и они короткие.

**Inline-bold**
Ключевые слова жирные прямо внутри абзаца. Читатель видит суть без чтения всего текста.

**Скриншот как доказательство**
Реальный скриншот (отзыв, метрика, переписка) с пунктирной рамкой вставляется как элемент карточки — не иллюстрация, а доказательство.

**Навигационная стрелка →**
Внизу справа. Сигнал "листай дальше" в карусели. Цвет — фирменный или белый.

**Чередование приёмов в серии**
При создании набора карточек приёмы работы с фото намеренно чередуются: текст на однородной зоне объекта, текст с overlay, текст с учётом границ объекта. Однообразие приёма снижает визуальный интерес серии — разнообразие держит внимание.

---

## Константы для всех форматов

- Один шрифт на карточку (меняется только вес и регистр) — кроме формата C
- Нет иконок, эмодзи, декоративных рамок
- Нет произвольных градиентов — только функциональные (свечение в B4)
- Воздух: контент не занимает всю площадь
